# 个人项目宇宙 · 综合作品中心导航主站 (Project Universe Hub)

这是一个专为个人开发者打造的**作品聚合导航主页**。它将你所有的**游戏项目、网站项目和软件项目**集中展示在一个统一、美观、充满科技感的门户网站中。

已成功接入本地 **MySQL 8.0 数据库**，支持通过网页图形界面或 Navicat 直接往数据库中添加、修改与管理新项目！

---

## 🗄️ 数据库接入信息

你的本地电脑中已自动创建并初始化好了专属数据库与数据表：

- **数据库服务**：MySQL 8.0 (`localhost:3306`)
- **数据库名**：`project_hub`
- **数据表**：`projects`
- **初始化脚本**：`server/schema.sql`
- **数据库配置**：见 `server/db.js`（默认使用 `root:123456`，可在 Navicat 中直接查看与编辑）

## 🚀 如何启动并体验？

### 推荐方式：双击启动 MySQL 服务（全功能）
1. 在本目录（`1.sum`）中，**直接双击 `start.bat`**。
2. 浏览器打开 **[http://localhost:3000](http://localhost:3000)**。
3. 此时网页右上角会显示绿色的 **`🟢 MySQL 已接入`** 标识，所有项目数据均从数据库实时加载！

### 降级模式：直接双击 `index.html`（离线静态）
如果不启动后台服务，直接双击打开 `index.html`，系统会自动检测并无缝降级为本地静态模式（从 `js/data.js` 读取备份数据），保证无论何时网页都能稳定打开。

## ➕ 以后如何新增一个游戏/网站/软件？

接入数据库后，添加新项目变得极其简单，支持以下 **3 种方式**：

### 方式 1：在网页端直接录入（最快、最直观）
1. 打开网页 [http://localhost:3000](http://localhost:3000)
2. 点击右上角 **「➕ 新增项目」**
3. 填入新项目名称、选择分类（🎮 游戏 / 🌐 网站 / 💻 软件）、架构（⚡ 纯前端 / 🚀 前+后端）、线上链接等
4. 点击 **「💾 直接保存到 MySQL 数据库」**
5. 数据库将立即写入新记录，网页即刻无缝刷新并展示全新项目卡片！

### 方式 2：使用 Navicat 可视化操作
1. 打开你电脑中的 **Navicat Premium**。
2. 连接本地连接（数据库名：`project_hub`）。
3. 打开 `projects` 表，直接在表格中新增一行并保存。
4. 刷新网页即可同步呈现。

### 方式 3：通过 RESTful API 添加
向后端发送 HTTP POST 请求：
```bash
POST http://localhost:3000/api/projects
Content-Type: application/json

{
  "title": "新项目名称",
  "category": "game",
  "architecture": "frontend",
  "status": "online",
  "playUrl": "http://172.197.217.156/my-new-game/",
  "summary": "一句话介绍核心玩法"
}
```

---

## 📡 后端 API 接口文档

- `GET /api/projects`：获取所有项目列表（从 MySQL 实时读取）
- `POST /api/projects`：新增项目（持久化到 MySQL）
- `PUT /api/projects/:id`：修改指定项目
- `DELETE /api/projects/:id`：从数据库中删除指定项目
- `GET /api/health`：服务与数据库连接健康检查

## 🌐 未来部署上线指引（供上线时参考）

当你后续准备将这个主页部署到云服务器（`172.197.217.156`）时：
1. 将本目录（`1.sum`）代码上传到服务器。
2. 在服务器上运行 `node server.js`，或将 MySQL 导出 SQL 导入云端数据库。
3. 配置 Nginx 反向代理将根路径 `/` 代理到此服务（3000端口）或托管静态文件，子路径分别路由到各个游戏，即可实现全自动化统一管理！
